# Melaporkan kerentanan

Jangan mengungkap credential atau detail eksploitasi melalui Issues publik.

Gunakan tab **Security → Advisories → Report a vulnerability** apabila private vulnerability reporting sudah diaktifkan. Jika tombol belum tersedia, hubungi **PENDING_SECURITY_EMAIL**. Jika kontak belum dikonfigurasi, buat Issue hanya untuk meminta kanal kontak privat, tanpa detail kerentanan.

Sertakan versi/platform, dampak, langkah reproduksi pada perangkat/data yang Anda kuasai, dan bukti yang disensor. Jangan menguji akun/server pengguna lain. Tidak ada program bounty atau SLA yang dijanjikan.

Rilis publik pertama sedang dipersiapkan; belum ada rentang versi dengan jaminan pemeliharaan. Setelah rilis, gunakan versi terbaru dan periksa catatan keamanan.

Vault tidak melindungi perangkat yang sudah dikuasai penyerang. Logout Google bukan remote revoke. Jika credential terekspos, ganti credential pada server terkait dan amankan akun/perangkat.
