# Bantuan

Gunakan tab **Issues → New issue** untuk bug atau permintaan fitur. Baca [batas yang diketahui](KNOWN_ISSUES.md) dan [panduan](docs/USER_GUIDE.md) dahulu.

Sertakan versi aplikasi/build, OS, arsitektur, langkah reproduksi, hasil yang diharapkan, dan pesan error yang telah disensor. Untuk masalah SSH sertakan tipe server tanpa alamat/credential asli. Dukungan diberikan sesuai ketersediaan; tidak ada SLA atau jaminan waktu respons.

Jangan unggah password, private key, token Google, database, backup, atau screenshot yang menampilkan rahasia. Laporan Issues dapat dilihat semua orang. Untuk kerentanan gunakan [kanal keamanan](SECURITY.md).

Kontribusi dokumentasi dan laporan reproduksi diterima. Kode sumber aplikasi tidak tersedia di repository ini. Donasi tidak diperlukan untuk memperoleh bantuan dan tidak menjamin prioritas atau implementasi fitur.
